EXISTING CAJUNWEBPRO SITE: USE UPDATE

For the existing 1.26.0 RC installation, use CajunWebPro-1.26.1-UPDATE.zip.
The updater recognizes the recorded release-file identity, not merely a version
label. The exact RC supplied for this site is included in that history. Other
recognized releases are checked by Verify and inspect before any file switch.

1. Back up the complete website, database, and configured PRIVATE STORAGE.
   Private storage may be outside public_html. Keep its encryption keys, uploaded
   customer files, and recovery records with the matching database backup.
2. Sign in to the existing administration account as an owner.
3. Extract the UPDATE archive into the current website root. It creates:
       cwp-update-1.26.1/
   The existing config.php and private storage must remain untouched. Do not copy
   the staging directory's site/ payload over the live website. Do not run the
   fresh installer on this existing installation.
4. Open this path on the SAME website origin in the signed-in browser:
       /cwp-update-1.26.1/owner-update.php
   For CajunWebPro:
       https://cajunwebpro.com/cwp-update-1.26.1/owner-update.php
   A current owner session needs no second password. A signed-out or expired
   session must sign in; this is normal authentication, not a removed protection.
5. Confirm the recoverable-backup checkbox, select Verify and inspect, and check
   the reported starting version. Then select Apply or retry update.
6. After Complete, open administration and confirm version 1.26.1. Open
   Settings > Version & database and use Verify & apply database update when
   needed. Feature-specific storage preparation remains explicit; the file
   updater does not silently enable payments, imports or provider operations.
7. Verify public pages, the admin dashboard, customer portal, callbacks and
   private downloads. Then remove ONLY the cwp-update-1.26.1 staging directory
   through the hosting file manager. Keep protected recovery files with backup.

If inspection reports customized/conflicting files, stop and reconcile those
files against your backup; do not delete configuration or reset the database.
During an interrupted file change the site uses maintenance protection. Keep
this staging directory and owner-update.php available for Apply or retry update
or Recover original files. File recovery is NOT database rollback. After schema
or business-data changes, restore only a coordinated, reviewed backup set.

WHERE THE NEW FEATURES ARE

Software & Licensing > Licenses & software: review the staged readiness status;
prepare licensing, the service catalog and software commerce as requested by
that screen. Create products and issue standard, trial, temporary or internal
master licenses. Customer-owned licenses and published private downloads appear
under My Software. Internal master keys are not customer downloads.

Master client portal: use the admin sidebar link. If client review has never
been prepared, follow Set up client access once and confirm its access policy.
Owner review uses the existing owner identity and audit trail, not a customer
password. Customer-only signatures and payment approvals remain separate.

Hosting & Domains > 20i workspace: Connection holds credentials, Existing
services is customer hosting inventory, and the overview links to Import 20i
plans, Manage products and prices, and Publish hosting offers. Available plans
come from the package-type catalog; importing a local draft is separate from
publishing an offer or provisioning a paid service. Set and review your own
prices and terms. The update does not import or provision anything silently.

Live card charging and provider operations remain separately gated. This update
is not an instruction to enable production payments. Do not send passwords or
API keys in a support conversation.

FRESH WEBSITE: COMPLETE-UPLOAD

CajunWebPro-1.26.1-COMPLETE-UPLOAD.zip is for a NEW installation only. Extract its
contents directly into the intended website directory; it has no site/ or
version wrapper. Open install.php over HTTPS and complete the one-page setup.
Do not use COMPLETE-UPLOAD to overwrite an installed site.

DEVELOPMENT / SOURCE: FULL-PROJECT

CajunWebPro-1.26.1-FULL-PROJECT.zip contains the project source, documentation,
tests and build tools. Do not extract it wholesale into a public website folder.
No customer CLI, Composer installation command or Node service is required.

These archives are alternatives, not nested ZIPs or sequential patches. Check
SHA256SUMS.txt and the individual manifests for exact source and file identity.
No automatic hosting deployment is performed. The target recovery journal uses
structure-1.26.1; the shared retained structure-1.11.0/mutex.php serializes older
and newer updater tools. Do not delete those private locks or recovery copies.
