The owner reviews a current complete returned list and explicitly assigns an individual provider domain identity to an active local client with the current owner password. Assignments retain profile revision, credential fingerprint, source observation, exact domain ID/name, client, revision and immutable events. Assigning or viewing a hosted domain never creates a registrar assignment. Reapproval cannot change the client or domain identity. Unlink affects only the local assignment and retains history; it does not transfer or cancel a registration.
